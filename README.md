# 부동산 매물관리 도구

사무실 직원이 원룸·투룸 등의 매물을 엑셀보다 빠르고 안전하게 관리하기 위한 **사무실 내부용 프로그램**입니다.

고객에게 공개하는 매물 사이트가 아닙니다. 건물, 호실, 이번 매물 조건을 기록하고, 같은 매물을 실수로 중복 등록하지 않도록 돕는 도구입니다.

## 현재 구현된 기능

현재 **4단계: 기존 건물 검색과 중복 방지**까지 구현되어 있습니다.

- 오늘의 매물 현황, 매물 등록·수정, 건물·호실 관리의 3개 메뉴
- 새 건물·새 호실·첫 매물을 한 번에 등록
- 건물명, 지번, 호수, 보증금, 월세 등 필수 입력값 확인
- 저장 전 입력 내용 요약 확인
- 건물 → 호실 → 매물 기록 순서로 데이터 저장
- 기존 건물명 또는 지번 검색
- 기존 건물을 선택한 뒤, 건물 공통정보를 다시 입력하지 않고 새 호실 등록
- 같은 건물 안에서 같은 호수 중복 등록 차단
- `302`와 `302호`를 같은 호실로 판단
- 공동현관·방문 비밀번호를 입력 화면에서 가려서 표시

아직 구현 예정인 기능은 건물·호실 상세 관리, 엑셀 내보내기, 백업·복구, 매물 회차에 연결한 계약 기간·상태 관리, 고객 이름·연락처를 포함한 간단한 상담 이력·다음 연락일 관리입니다.

자세한 단계별 진행 상황은 [현재 구현 진행 상황](docs/current_implementation_status.md)에서 확인할 수 있습니다.

## 실행 방법

### 1. 준비

Python이 설치된 Windows PC에서 프로젝트 폴더를 엽니다.

필요한 프로그램 구성요소를 설치합니다.

```powershell
python -m pip install -r requirements.txt
```

### 2. 프로그램 실행

프로젝트 폴더에서 아래 명령을 실행합니다.

```powershell
streamlit run app.py
```

실행 후 브라우저에서 아래 주소를 엽니다.

```text
http://127.0.0.1:8501
```

프로그램을 멈추려면 명령 창에서 `Ctrl + C`를 누릅니다.

## 데이터가 저장되는 곳

등록한 데이터는 아래 파일에 저장됩니다.

```text
storage/real_estate.db
```

이 파일에는 매물 정보와 내부정보가 포함될 수 있으므로, 임의로 삭제·이동·공유하면 안 됩니다.

## 중요한 사용 주의사항

- 이 도구는 사무실 내부에서만 사용합니다. 인터넷에 공개하지 않습니다.
- 공동현관 비밀번호, 방문 비밀번호, 내부 메모는 외부에 공유하지 않습니다.
- 현재 데이터 파일을 Google Drive, OneDrive 같은 동기화 폴더에서 직접 실행하지 않습니다.
- 프로그램을 업데이트하기 전에는 데이터 파일을 별도로 복사해 백업합니다.
- 같은 호실이 다시 매물로 나왔을 때의 재등록 기능은 아직 개발 중입니다. 현재는 기존 호실을 다시 새 호실로 등록할 수 없습니다.

## 폴더 구성

```text
realestate/
├─ app.py                         프로그램 실행 파일
├─ ui/                            사용자가 보는 화면
├─ services/                      입력값 확인과 저장 규칙
├─ storage/                       데이터 저장 기능과 실제 데이터 파일
└─ docs/                          기획, 작업 계획, 진행 기록 문서
```
