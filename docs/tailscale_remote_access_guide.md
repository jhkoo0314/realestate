# 부동산 매물관리 — Tailscale 원격 접속 안내

> 대상: 사무실의 메인 PC 한 대와 업무용 사용자 PC 한 대를 안전하게 연결할 때
>
> 이 문서는 인터넷에 프로그램을 공개하지 않고, 허가된 PC에서만 접속하기 위한 안내입니다.

## 1. Tailscale은 무엇인가

Tailscale(테일스케일)은 등록한 PC끼리만 연결해 주는 안전한 전용 통로입니다.

이 프로그램에서는 다음처럼 사용합니다.

```text
메인 PC
├─ 부동산관리 프로그램 실행
└─ 실제 데이터 파일 1개 보관
        ▲
        │ Tailscale 전용 연결
        │
사용자 PC
└─ 웹브라우저로 프로그램 사용
```

- **메인 PC**: 프로그램과 실제 데이터 파일을 보관하는 컴퓨터입니다.
- **사용자 PC**: 웹브라우저로 화면만 열어 사용하는 컴퓨터입니다.
- 사용자 PC에는 `real_estate.db` 파일을 복사하거나 직접 열지 않습니다.

## 2. 가장 중요한 전제

메인 PC가 꺼져 있거나, 메인 PC에서 프로그램이 실행되지 않으면 다른 PC에서는 입력·조회·저장을 할 수 없습니다.

저장된 정보가 사라지는 것은 아닙니다. 정보는 메인 PC의 데이터 파일에 남아 있고, 메인 PC와 프로그램을 다시 켜면 사용할 수 있습니다.

업무시간에 계속 사용해야 한다면, 자주 끄지 않는 사무실 공용 PC를 메인 PC로 정하는 것이 좋습니다.

## 3. 설치 전에 정할 것

- 메인 PC: 프로그램과 데이터 파일을 둘 사무실 PC 1대
- 사용자 PC: 접속해서 사용할 업무용 PC
- Tailscale 관리자: 기기 추가와 사용자 초대를 관리할 사람 1명
- Tailscale 계정: 직원끼리 한 계정을 공유하지 말고, 각자 본인 계정으로 초대받아 사용합니다.

개인 PC가 아닌 사무실용 계정 또는 사무실 이메일을 관리 계정으로 쓰는 편이 담당자 변경 시 안전합니다.

## 4. 처음 한 번만 하는 설치

### 4-1. 메인 PC에 Tailscale 설치

1. 메인 PC에서 [Tailscale Windows 다운로드 페이지](https://tailscale.com/download/windows)를 엽니다.
2. Tailscale을 설치하고 실행합니다.
3. 사무실에서 정한 관리자 계정으로 로그인합니다.
4. 웹브라우저에서 Tailscale 관리 화면을 열어 메인 PC가 목록에 보이는지 확인합니다.
5. 목록에서 이 PC 이름을 알아보기 쉽게 바꿉니다. 예: `realestate-main`

### 4-2. 사용자 PC에 Tailscale 설치

1. 사용자 PC에도 Tailscale을 설치합니다.
2. 사용자의 본인 계정으로 로그인합니다.
3. Tailscale 관리자는 관리 화면에서 해당 사용자를 사무실 네트워크에 초대합니다.
4. 초대를 받은 사용자가 수락하면, 메인 PC와 사용자 PC가 같은 Tailscale 전용 연결 안에 들어옵니다.

기기 목록에서 두 PC 모두 연결됨으로 보이는지 확인합니다.

## 5. 메인 PC에서 프로그램 실행

메인 PC에서만 아래 작업을 합니다.

1. `C:\realestate` 폴더를 엽니다.
2. PowerShell(파란색 또는 검은색 명령 창)을 엽니다.
3. 아래 명령을 입력합니다.

```powershell
streamlit run app.py --server.address 0.0.0.0
```

4. 열린 창은 **닫지 말고 최소화**합니다. 이 창을 닫으면 다른 PC의 접속도 끊깁니다.
5. 메인 PC 브라우저에서 `http://127.0.0.1:8501`을 열어 프로그램이 정상인지 확인합니다.

처음 실행할 때 Windows가 네트워크 허용 여부를 물으면, **공용 네트워크 허용은 선택하지 않습니다.** 아래 6단계의 방화벽 설정을 먼저 확인합니다.

## 6. Windows 방화벽 설정: Tailscale 연결만 허용

이 설정은 메인 PC에서 한 번만 합니다. 목적은 포트 8501을 사무실 인터넷 전체에 열지 않고, Tailscale 연결에서만 쓰게 하는 것입니다.

1. Windows 시작 메뉴에서 `Windows Defender 방화벽(고급 보안)`을 검색해 엽니다.
2. 왼쪽에서 `인바운드 규칙`을 선택합니다.
3. 오른쪽에서 `새 규칙` → `포트`를 선택합니다.
4. `TCP`, `특정 로컬 포트`에 `8501`을 입력합니다.
5. `연결 허용`을 선택합니다.
6. 프로필은 `개인`, `공용`은 해제하고, 회사 PC 설정에 맞는 `도메인` 또는 `개인`만 선택합니다.
7. 규칙 이름은 `부동산관리 - Tailscale 접속`으로 적습니다.
8. 새로 만든 규칙을 더블클릭한 뒤 `범위` 탭을 엽니다.
9. `원격 IP 주소`에서 `다음 IP 주소`를 선택하고 `100.64.0.0/10`을 추가합니다.
10. 저장합니다.

이 범위는 Tailscale 기기에 사용하는 전용 주소 범위입니다. 설정 화면이 다르거나 확신이 없으면, 방화벽을 임의로 넓게 열지 말고 담당자에게 확인합니다.

## 7. 사용자 PC에서 접속하는 방법

1. 메인 PC가 켜져 있고, Tailscale이 연결되어 있으며, 프로그램 실행 창이 열려 있는지 확인합니다.
2. 사용자 PC에서도 Tailscale이 연결되어 있는지 확인합니다.
3. Tailscale 관리 화면의 메인 PC 상세에서 `Tailscale IP` 주소를 확인합니다. 예: `100.101.102.103`
4. 사용자 PC의 브라우저 주소창에 아래처럼 입력합니다.

```text
http://100.101.102.103:8501
```

5. 매물관리 화면이 열리면, 매물 조회와 입력을 할 수 있습니다.

처음에는 숫자 주소를 쓰는 편이 가장 헷갈리지 않습니다. 나중에 Tailscale의 기기 이름 연결(MagicDNS)을 설정했다면, 관리자가 알려 준 전용 기기 이름으로도 접속할 수 있습니다.

## 8. 매일 사용하는 순서

### 메인 PC 담당자

1. 메인 PC를 켭니다.
2. Tailscale이 연결되었는지 확인합니다.
3. 부동산관리 프로그램을 실행합니다.
4. 메인 PC에서 화면이 열리는지 확인합니다.
5. 사용자에게 “사용 가능”을 알립니다.

### 사용자 PC 담당자

1. Tailscale이 연결되었는지 확인합니다.
2. 브라우저에서 저장해 둔 메인 PC 접속 주소를 엽니다.
3. 등록 또는 수정 후, 목록에서 저장 결과를 확인합니다.

## 9. 접속이 안 될 때 확인 순서

1. 메인 PC가 켜져 있는가?
2. 메인 PC에서 Tailscale이 연결됨으로 표시되는가?
3. 메인 PC의 프로그램 실행 창이 열려 있는가?
4. 메인 PC에서 `http://127.0.0.1:8501`이 열리는가?
5. 사용자 PC에서도 Tailscale이 연결됨으로 표시되는가?
6. 접속 주소의 숫자와 `:8501`이 맞는가?
7. 메인 PC의 방화벽 규칙이 Tailscale 전용 주소 범위를 허용하는가?

그래도 안 되면 오류 화면을 캡처하고, 두 PC의 Tailscale 연결 상태와 메인 PC의 프로그램 실행 창을 함께 확인합니다. 데이터 파일을 사용자 PC로 복사해서 해결하려고 하면 안 됩니다.

## 10. 절대 하지 않을 것

- 공유기에서 포트 포워딩을 설정하지 않습니다.
- Tailscale Funnel 같은 인터넷 공개 기능을 켜지 않습니다.
- 프로그램 접속 주소를 불특정 다수에게 보내지 않습니다.
- `storage\real_estate.db`를 Google Drive·OneDrive·공유폴더에서 직접 실행하지 않습니다.
- 사용자 PC에 데이터 파일을 복사해 따로 실행하지 않습니다.
- 메인 PC의 데이터 파일을 백업 확인 없이 이동·삭제·덮어쓰지 않습니다.
- Tailscale 계정 비밀번호를 직원끼리 공유하지 않습니다.

## 11. 담당자 변경 또는 기기 교체 시

1. 새 담당자를 Tailscale 관리자로 추가합니다.
2. 새 PC에서 Tailscale과 프로그램 접속을 먼저 확인합니다.
3. 더 이상 쓰지 않는 PC와 퇴사자 계정의 접근을 Tailscale 관리 화면에서 제거합니다.
4. 메인 PC를 바꾸는 경우에는 먼저 전체 백업과 복구 확인을 합니다. 데이터 파일을 단순히 여러 PC에 복사해 동시에 사용하지 않습니다.
