# 부동산 매물관리 프로그램 — 광고문구 생성기 빌드 계획서

## 1. 프로젝트 목적

현재 매물관리 프로그램에서 사용 중인 광고 템플릿을 개선하여, **매물 설명만 하는 광고가 아니라 상담리드를 발생시키는 광고문구**를 빠르게 생성할 수 있도록 한다.

핵심 목표는 세 가지다.

1. 매물 정보를 다시 입력하지 않고 기존 등록 데이터를 활용한다.
2. 광고 구조는 일정하게 유지하되 문구는 사용자가 자유롭게 수정할 수 있다.
3. 특정 매물이 마음에 들지 않는 고객도 **다른 매물 상담으로 연결**되도록 한다.

이 기능의 목적은 AI로 매번 새로운 글을 만드는 것이 아니다.

> **검증된 광고 구조 + 매물 데이터 자동입력 + 문구 선택/수정**

방식으로 반복 작업을 최소화하는 것이 핵심이다.

---

# 2. 핵심 운영 방향

기존 광고는 매물 설명 비중이 높았다.

앞으로는 광고문구를 대략 다음 구조로 변경한다.

**중개서비스 및 상담유도 20~30%  
+ 해당 매물 설명 60~70%  
+ 필수 안내사항 10%**

즉,

> “이 방이 좋습니다.”

에서 끝나는 것이 아니라

> “이 방이 아니더라도 원하는 조건을 말씀해주시면 다른 매물까지 찾아드립니다.”

라는 흐름을 기본 구조에 포함한다.

---

# 3. 광고문구 기본 구조

모든 광고는 아래 7개 블록을 기본으로 한다.

### BLOCK 1. 상단 상담 유도

광고를 열자마자 고객에게 **해당 매물 외에도 상담할 이유**를 제공한다.

기본 예시:

★ 찾으시는 조건에 맞춰 다양한 매물을 비교해드립니다.  
★ 광고 매물이 조건에 맞지 않아도 다른 매물 안내 가능합니다.  
★ 보증금·월세·입주일 말씀해주시면 맞는 매물을 찾아드립니다.

이 영역은 사용자가 직접 문구를 수정할 수 있어야 한다.

---

### BLOCK 2. 3줄 핵심 요약

해당 매물의 가장 강한 장점만 최대 3개 노출한다.

예:

◇ 3줄 요약  
# 깔끔하게 관리된 신축급 원룸  
# 넉넉한 붙박이장과 풀옵션 구성  
# 엘리베이터·주차 가능

매물마다 자동으로 다른 내용이 들어간다.

---

### BLOCK 3. 위치 정보

예:

◇ 위치 정보  
# 장재리 1684  
# 천안아산역·배방 생활권 이용 편리

기존처럼 생활권 설명을 여러 문장 반복하지 않는다.

**1~2문장으로 제한한다.**

---

### BLOCK 4. 가격 정보

예:

◇ 가격 정보  
# 보증금 500 / 월세 40  
# 관리비 8만원

매물 DB의 가격정보를 자동으로 불러온다.

---

### BLOCK 5. 옵션 및 특징

예:

◇ 옵션 정보  
# 에어컨 / 냉장고 / 세탁기 / TV / 가스레인지  
# 붙박이장 / 엘리베이터 / 주차 가능

옵션 전체를 무조건 표시하지 않고 광고에 필요한 주요 옵션만 표시한다.

---

### BLOCK 6. 대체매물 상담 유도

이번 개편에서 가장 중요한 영역이다.

기본 예시:

☎ 찾으시는 조건이 따로 있으신가요?

현재 매물이 조건에 맞지 않더라도 괜찮습니다.  
원룸·투룸 매물을 다양하게 보유하고 있어  
예산 / 입주일 / 위치 / 주차 등 조건을 말씀해주시면  
맞는 매물을 함께 찾아드립니다.

이 영역의 목적은 **특정 매물 문의 → 고객 상담리드 전환**이다.

---

### BLOCK 7. 안내사항

기존 필수 안내문구는 유지하되 간결하게 만든다.

예:

📌 안내사항

✔ 본 매물은 실매물입니다.  
✔ 사진은 실제 호실 촬영본이며 촬영 시점에 따라 차이가 있을 수 있습니다.  
✔ 다가구주택은 호실별 전용면적을 참고용으로 안내드립니다.  
✔ 계약 가능 여부 및 옵션은 실시간으로 변경될 수 있습니다.  
✔ 방문 전 문의 부탁드립니다.

# 4. 광고문구 생성 화면

## 화면 위치

매물관리 프로그램의 기존 매물 상세화면에

**[광고문구 생성]**

버튼 또는 별도 탭을 추가한다.

예:

`매물정보 | 사진 | 상담 | 계약 | 광고문구`

# 5. 광고문구 생성 흐름

사용자가 광고문구 화면으로 들어오면 다음 순서로 작동한다.

### STEP 1. 매물 선택

기존 매물 DB에서 매물을 선택한다.

자동으로 불러올 정보:

- 주소
- 매물종류
- 보증금
- 월세
- 관리비
- 층수
- 옵션
- 주차
- 엘리베이터
- 입주가능일
- 방향
- 건물연식
- 특이사항
- 매물 장점

---

### STEP 2. 광고 템플릿 선택

예:

`템플릿 ▼`

- 원룸 기본형
- 원룸 저가형
- 원룸 신축형
- 원룸 단기형
- 투룸 기본형
- 투룸 신축형
- 투룸 가성비형
- 현장근로자형

초기에는 **현재 운영 중인 템플릿을 최대한 재사용**한다.

템플릿 수를 불필요하게 늘리지 않는다.

# 6. 광고문구 편집 방식

광고 전체를 하나의 큰 텍스트박스에 넣지 않는다.

각 영역을 따로 편집할 수 있도록 한다.

예:

### 상단 상담문구

[ 찾으시는 조건에 맞춰 다양한 매물을 비교해드립니다. ]

### 핵심요약 1

[ 깔끔하게 관리된 신축급 원룸 ]

### 핵심요약 2

[ 넉넉한 붙박이장과 풀옵션 구성 ]

### 위치 설명

[ 천안아산역과 배방생활권 이용이 편리합니다. ]

### 상담유도 문구

[ 해당 매물이 조건에 맞지 않아도 다른 매물 안내 가능합니다. ]

### 안내사항

[ 기본 안내문구 ]

각 칸을 사용자가 자유롭게 수정할 수 있도록 한다.

# 7. 문구 프리셋 기능

자주 쓰는 문장은 매번 직접 입력하지 않고 선택하도록 한다.

예를 들어 **상단 상담문구**에는 다음 프리셋을 등록한다.

### 프리셋 A — 비교형

★ 다양한 매물을 비교해 가장 좋은 조건으로 안내드립니다.

### 프리셋 B — 상담형

★ 보증금·월세·입주일 말씀해주시면 조건에 맞는 매물을 찾아드립니다.

### 프리셋 C — 대체매물형

★ 광고 매물이 조건에 맞지 않아도 다른 매물 안내 가능합니다.

사용자는 Dropdown 또는 버튼으로 선택하고 필요하면 직접 수정한다.

---

# 8. 문구 관리 기능

별도 메뉴를 만든다.

`설정 → 광고문구 관리`

여기에서 사용자가 직접 기본 문구를 수정할 수 있다.

예:

| 구분 | 문구 |
|---|---|
| 상단문구 1 | 다양한 매물을 비교해드립니다 |
| 상단문구 2 | 조건에 맞는 매물을 찾아드립니다 |
| 상담유도 1 | 이 방이 아니어도 상담 가능합니다 |
| 단기강조 | 단기계약 가능한 매물 안내 가능합니다 |
| 주차강조 | 차량 보유 고객에게 적합합니다 |
| 신축강조 | 깔끔한 신축급 컨디션입니다 |

기능:

**수정 / 추가 / 삭제 / 기본값 복원**

이 정도만 구현한다.

# 9. 매물 특성에 따른 자동문구

DB의 정보를 활용하여 기본 문구를 자동 생성한다.

예를 들어

`엘리베이터 = 있음`

이라면

> 엘리베이터 있어 층간 이동이 편리합니다.

`주차 = 가능`

이라면

> 차량 보유 고객도 편리하게 이용 가능합니다.

`단기계약 = 가능`

이라면

> 단기 거주를 원하는 분도 상담 가능합니다.

`신축급 = YES`

라면

> 깔끔하게 관리된 신축급 컨디션

이런 식으로 문장을 자동 제안한다.

---

# 10. 자동생성 원칙

AI가 새로운 사실을 만들어서는 안 된다.

광고문구 생성기는 반드시

**DB에 있는 사실 → 사전에 등록된 표현**

방식으로만 기본 문구를 생성한다.

예:

DB

`주차 = 가능`

↓

문구

`# 주차 가능`

DB

`붙박이장 = 있음`

↓

문구

`# 넉넉한 수납이 가능한 붙박이장`

따라서 허위 또는 과장 광고 가능성을 최소화한다.

# 12. 편집 UX

광고문구 작성 시 사용자가 가장 많이 하는 작업은

**생성 → 조금 수정 → 복사**

이므로 화면 역시 이 과정에 맞춘다.

추천 화면 구조:

### 좌측

**매물정보 + 템플릿 + 문구 편집**

### 우측

**실시간 광고 미리보기**

화면이 좁은 경우에는

**편집 영역 → 미리보기**

순서로 세로 배치한다.

# 13. 반드시 필요한 버튼

광고문구 생성 화면 하단에는 다음 버튼만 둔다.

**[광고 생성]**

DB 정보를 기반으로 기본 광고 생성

**[문구 복사]**

완성 광고 전체 복사

**[수정내용 저장]**

해당 매물의 수정된 광고 저장

**[기본값 복원]**

템플릿 기본문구로 복원

불필요한 기능은 추가하지 않는다.

# 14. 매물별 광고 저장

한 번 수정한 광고문구는 매물별로 저장한다.

예:

`장재리 1684`

기본 템플릿 생성

↓

사용자가 문구 수정

↓

저장

↓

다음에 해당 매물을 열면 수정된 광고가 그대로 표시

이를 통해 매번 광고를 다시 작성하는 일을 없앤다.

# 16. 1차 버전에서 제외할 기능

초기 버전에는 다음 기능을 넣지 않는다.

- ChatGPT API 연동
- 자동 AI 광고작성
- SEO 점수
- 광고 자동 업로드
- 네이버·직방·당근 API 연결
- 광고 성과 자동수집
- 고객별 자동 추천
- 복잡한 광고 A/B 테스트 시스템

필요성이 실제 운영에서 확인된 이후 추가한다.

# 17. 향후 확장 가능 기능

향후에는 광고 성과 데이터를 연결할 수 있다.

예:

| 매물 | 채널 | 광고비 | 클릭 | 문의 | 방문 | 계약 |
|---|---|---:|---:|---:|---:|---:|
| A | 당근 | 5,000 | 70 | 3 | 2 | 1 |
| B | 당근 | 4,000 | 100 | 0 | 0 | 0 |

이를 통해 향후

**“어떤 템플릿이 문의를 많이 만드는가”**

를 분석할 수 있다.

하지만 이것은 광고문구 생성기 MVP가 안정화된 이후 구현한다.

# 18. 가장 중요한 개선점

기존 광고 구조:

**매물소개  
→ 특징  
→ 위치  
→ 옵션  
→ 안내사항**

개선 구조:

**상담 이유  
→ 핵심 매물정보  
→ 장점  
→ 가격·옵션  
→ 다른 매물 상담유도  
→ 안내사항**

핵심 변화는 하나다.

> **매물을 설명하는 광고에서 상담을 발생시키는 광고로 변경한다.**

# 19. 개발 우선순위

## 1단계 — 기존 광고 생성 화면 수정

- 상단 상담문구 추가
- 대체매물 상담문구 추가
- 기존 설명 중 반복문장 제거
- 미리보기 구조 개선

## 2단계 — 문구 수정 기능

- 블록별 텍스트 수정
- 실시간 미리보기
- 매물별 광고문구 저장

## 3단계 — 문구 프리셋

- 상단문구
- 상담유도
- 신축
- 저가
- 단기
- 주차 등

선택 가능한 문구 라이브러리 구현

## 4단계 — 템플릿 관리

사용자가 직접

- 템플릿 수정

# 22. 개발 시 핵심 원칙

이 기능의 성공 기준은 **문장을 얼마나 멋지게 생성하느냐가 아니다.**

실제 업무에서

> 매물을 클릭하고 → 30초 정도 확인하고 → 광고문구를 복사

할 수 있어야 한다.

따라서 복잡한 AI 시스템을 만들기보다

**기존 매물 DB + 검증된 광고 템플릿 + 수정 가능한 문구 프리셋**

세 가지를 결합하는 것을 우선한다.

최종 목적은 광고 작성시간 단축이면서 동시에,

> **특정 매물 광고를 통해 들어온 고객을 다른 매물까지 상담할 수 있는 리드로 전환하는 것**

이다.
