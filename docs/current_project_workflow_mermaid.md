## 1. 전체 메뉴와 업무 연결

```mermaid
flowchart TD
    START[사무실 직원] --> MENU{업무 선택}
    MENU --> TODAY[오늘 할 일]
    MENU --> LISTING[매물 등록·수정]
    MENU --> DASH[매물 현황 리스트]
    MENU --> BUILDING[건물·호실 관리]
    MENU --> CONSULT[상담관리]
    MENU --> CONTRACT[계약관리]
    MENU --> AD[광고관리]

    LISTING --> INVENTORY[(건물 · 호실 · 매물 회차)]
    BUILDING --> INVENTORY
    DASH --> INVENTORY
    CONSULT --> CONSULT_DATA[(상담 · 상담 활동)]
    CONTRACT --> CONTRACT_DATA[(계약 · 계약 단계 이력)]
    AD --> AD_COST[(월별 광고비)]

    CONSULT_DATA -. 원본 상담 연결 .-> CONTRACT_DATA
    CONTRACT_DATA -. 계약 상태 반영 .-> INVENTORY
    TODAY -. 날짜 기준 조회 .-> INVENTORY
    TODAY -. 날짜 기준 조회 .-> CONSULT_DATA
    TODAY -. 날짜 기준 조회 .-> CONTRACT_DATA
```

## 2. 매물 등록·수정 흐름

```mermaid
flowchart TD
    A[매물 등록·수정 열기] --> B[건물명 또는 지번 검색]
    B --> C{기존 건물 존재?}
    C -- 아니오 --> D[새 건물 정보 입력]
    D --> E[새 호실 정보 입력]
    C -- 예 --> F[기존 건물 선택]
    F --> G{기존 호실 존재?}
    G -- 아니오 --> E
    G -- 예 --> H[최신 매물 정보 수정]
    E --> I[첫 매물 조건 입력]
    I --> J[건물 · 호실 · 첫 매물 함께 저장]
    H --> K[같은 매물 회차만 갱신]
    J --> L[(건물 · 호실 · 매물 회차 저장)]
    K --> L
    L --> M[자동 백업 · 무결성 검사]

    N[호실 옵션] -. 매물 등록·수정에서는 입력하지 않음 .-> O[건물·호실 관리에서만 확인·수정]
```

## 3. 상담부터 계약 완료까지

```mermaid
flowchart TD
    A[상담관리] --> B{상담 구분}
    B -- 매물 상담 --> C[상담 당시 매물 회차 선택]
    B -- 일반 상담 --> D[매물 없이 상담 등록]
    C --> E[상담 정보 입력]
    D --> E

    E --> F[유입 경로 · 희망 지역 · 희망 방 유형 · 예산 · 입주일]
    F --> G[희망 지역·방 유형은 복수 선택]
    G --> H[기타 선택 시에만 직접 입력]
    H --> I[다음 연락일은 사용자 수동 입력]
    I --> J[(상담 저장)]

    J --> K[후속 전화 · 문자 · 방문 이력 추가]
    K --> L[최근 상담일 · 방문 결과 · 다음 연락일 요약 갱신]
    L --> M{계약으로 이어짐?}
    M -- 아니오 --> N[상담 계속 또는 종료]
    N --> O[종료 사유는 선택 입력]
    M -- 예 --> P[계약관리에서 실제 계약 매물 선택]
    P --> Q[원본 상담 선택 또는 상담 없이 계약]
    Q --> R[계약자 정보 자동 초기 입력 · 상담 요약 확인]
    R --> S[(계약 저장)]

    S --> T{계약 상태}
    T -- 계약 진행 · 잔금 예정 --> U[연결 상담을 계약 진행으로 반영]
    T -- 계약 완료 --> V[다른 진행 계약 확인]
    V -- 없음 --> W[연결 상담 종료 · 다음 연락일 해제]
    V -- 있음 --> X[상담 진행 상태 유지]
    T -- 해지 · 만료 --> Y[상담 자동 재개하지 않음]
```

## 4. 상담 집중 대응과 오늘 할 일

```mermaid
flowchart TD
    A[(진행 중 상담)] --> B{다음 연락일 존재?}
    B -- 오늘 --> C[집중 대응: 다음 연락 오늘]
    B -- 지남 --> D[집중 대응: 다음 연락 지연]
    B -- 미래 --> E[해당 날짜까지 대기]
    B -- 없음 --> F{상담일 기준 경과일}
    F -- 0~1일 --> G[집중 대응: 24시간 이내 1차 추천 확인]
    F -- 2~3일 --> H[집중 대응: 72시간 이내 추가 추천 확인]
    F -- 4일 이상 --> I[일반 진행 상담]

    C --> J[오늘 할 일: 상담 업무]
    D --> K[오늘 할 일: 지연 상담 업무]
    J --> L[완료 체크]
    K --> L
    L -. 원본 상담 상태·날짜는 변경하지 않음 .-> M[완료 기록만 저장]

    N[종료 또는 계약 완료 상담] --> O[집중 대응·다음 연락 목록에서 제외]
```

## 5. 계약 일정과 매물 상태 반영

```mermaid
flowchart LR
    A[계약 등록 또는 계약 단계 이력] --> B{계약 상태}
    B -- 계약 진행 --> C[매물: 계약 진행 중]
    B -- 잔금 예정 --> C
    B -- 계약 완료 --> D[매물: 계약 완료 후 종료]
    B -- 해지 또는 만료 --> E[매물: 공실]

    F[정식 계약일 · 추가 계약금 예정일 · 잔금 예정일 · 임대차 종료일] --> G[계약 일정]
    G --> H[오늘 할 일]
    H --> I[오늘 · 지연 · D-1 잔금 알림]
```

## 6. 광고관리 흐름

```mermaid
flowchart TD
    A[광고관리] --> B{메뉴 선택}
    B --> C[월별 광고비 기록]
    B --> D[광고 문구 만들기]

    C --> E[기준연월 · 채널 · 월 광고비 · 메모 입력]
    E --> F{같은 연월·채널 존재?}
    F -- 예 --> G[기존 금액·메모 수정]
    F -- 아니오 --> H[새 월별 광고비 저장]
    G --> I[(monthly_advertising_costs)]
    H --> I

    D --> J[지역 · 방 형태 · 가격 등 직접 입력]
    J --> K[광고 문구 생성 · 화면에서 수정·복사]
    K -. 입력값과 결과는 저장하지 않음 .-> L[완료]

    M[매물별 광고 조회 · 연결 · 게시 상태] -. 제공하지 않음 .-> N[없음]
    O[광고비 효율 · 전환율 성과 리포트] -. 제공하지 않음 .-> N
```

## 7. 데이터 보존과 백업 원칙

```mermaid
flowchart TD
    A[저장 · 수정 · 삭제 성공] --> B[SQLite 거래 완료]
    B --> C[온라인 백업 생성]
    C --> D[무결성 검사]
    D -- 통과 --> E[OneDrive 날짜별 백업 갱신]
    D -- 실패 --> F[백업 실패 기록]

    G[기존 자유입력 상담값] --> H[자동 변환하지 않음]
    I[기존 분리형 원룸 · 호실 옵션 값] --> J[삭제하지 않고 기존 기록으로 보존]
    K[매물별 광고 42건] --> L[전환 전 보호 백업 보관]
```

## 현재 범위에서 하지 않는 일

- 매물별 광고 조회·연결·게시 상태 관리
- 상담·방문·계약 전환율 또는 광고비 효율 성과 리포트
- 다음 연락일 자동 제안·자동 변경
- 종료 사유 미입력 경고 또는 저장 차단
- 자동 문자, 방문 예약, 외부 광고 자동 등록
