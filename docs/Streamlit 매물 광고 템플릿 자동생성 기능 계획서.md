# Streamlit 매물 광고 템플릿 자동생성 기능 계획서

## 1. 목적

당근부동산·직방·네이버 등 광고 플랫폼에 사용할 광고 제목과 상세문구를 빠르게 생성할 수 있는 기능을 추가한다.

현재는 매물별로 문구를 새로 작성하거나 ChatGPT에 정보를 입력한 뒤 복사하는 방식이기 때문에 반복작업이 많다. 기존 광고가 수십 건인 상황에서 광고 현황을 매물 DB와 하나씩 맞추는 작업까지 늘리지 않는다.

이번 기능의 목적은 AI를 매번 호출하는 것이 아니라, 미리 정의된 광고 템플릿과 매물 데이터를 조합하여 다음 과정을 단순화하는 것이다.

**기본 조건 직접 입력 → 템플릿 선택 → 강조 포인트 선택 → 광고 생성 → 복사**

핵심 목표는 광고문구의 완전 자동화가 아니라, 반복적인 광고 작성 시간을 줄이고 광고 품질을 일정하게 유지하는 것이다.

---

# 2. 구현 원칙

이번 기능은 기존 Streamlit 매물관리 프로그램 내부에 추가한다.

새로운 별도 프로그램이나 복잡한 백엔드는 만들지 않는다. 기존 `광고관리` 탭 안에 `광고 문구 만들기` 하위 메뉴를 추가한다.

광고 문구 생성은 현재 매물 DB·광고 현황과 연결하지 않는다. 광고를 올리기 전 매물을 등록하지 않아도 바로 사용할 수 있게, 필요한 최소 조건을 화면에서 직접 입력한다.

광고 생성에는 OpenAI API 등의 AI API를 사용하지 않는다.

기본 구조는 다음과 같다.

**70% 고정 템플릿 + 30% 매물별 데이터 및 특징**

예:

```text
템플릿
+
매물 기본정보
+
선택한 핵심 특징
+
특징별 문장
+
공통 안내사항
=
최종 광고문
```

기능의 핵심은 복잡한 자동화가 아니라 실무자가 빠르게 광고를 완성하는 것이다. 광고 현황 관리는 채널·상태 확인용으로 계속 분리해 둔다.

# 3. 사용자 업무 흐름

## STEP 1. 기본 조건 직접 입력

현재 매물 DB를 검색하거나 선택하지 않는다. 광고를 올리기 전 매물을 등록하지 않아도 바로 사용할 수 있게 아래 최소 조건만 직접 입력한다.

```text
지역 또는 지번: 북수리 (선택)
방 형태: 투룸
보증금 / 월세: 300 / 55
입주 가능일: 즉시 가능 (선택)
```

필수 입력은 방 형태와 보증금·월세다. 교통·생활 장점·추가 핵심 포인트는 선택 입력으로 두며, 실제 확인한 내용만 줄마다 입력한다.

지역은 자유 입력을 유지하되, `북수리 / 공수리 / 장재리 / 월천지구`를 빠르게 선택할 수 있게 한다. 이 네 지역을 선택했더라도 지역 장점 문구는 자동으로 넣지 않고, 아래의 `지역 생활권 강조`에서 매물 위치를 확인한 뒤 직접 선택한다.

# 4. 광고 작성 화면

광고 작성 화면은 최대한 단순하게 구성한다. 기존 `현재 광고 현황` 및 `매물에 광고 채널 연결`과 데이터를 주고받지 않는다.

## 화면 구조

### ① 기본 조건 입력

```text
[ 지역 또는 지번 ] [ 북수리 ]
[ 방 형태 ] [ 투룸 ▼ ]
[ 보증금 (만원) ] [ 300 ] [ 월세 (만원) ] [ 55 ]
[ 입주 가능일 (선택) ] [ 즉시 가능 ]
```

---

### ② 템플릿 선택

```text
[ 광고 템플릿 ▼ ]
```

초기 템플릿은 원룸 기본형·원룸 옵션형·투룸 기본형·투룸 공간·수납형 4종으로 시작한다. 나머지 템플릿은 실제 사용 빈도를 확인한 뒤 추가한다.

# 6. 강조 포인트 선택 기능

사용자가 광고에서 강조하고 싶은 특징을 직접 선택한다. DB에서 자동으로 선택하거나 확인하지 않는다.

예:

```text
광고 강조 포인트

☑ 붙박이장
☑ 베란다
☑ 양창
☐ 엘리베이터
☑ 주차 가능
☐ 신축급
☐ 중문
☐ 풀옵션
```

광고에는 모든 정보를 무조건 넣지 않는다.

사용자가 선택한 핵심 포인트를 우선적으로 사용한다.

권장 선택 개수:

**2~5개**

너무 많은 장점을 나열하지 않고 실제 문의에 영향을 줄 수 있는 특징만 강조한다.

---

## 6-1. 핵심 지역 생활권 강조 문구

광고 작성 화면에 `지역 생활권 강조 (선택)` 영역을 추가한다. 지역을 선택하면 해당 지역의 검토된 문구 후보를 체크박스로 보여 주고, 실무자가 필요한 문구를 여러 개 선택하면 광고 본문의 `교통 & 생활` 위치에 각각 넣는다.

지역명만으로 매물의 실제 도보거리·역 접근성·상권 접근성을 단정할 수 없으므로, 자동 선택이나 자동 삽입은 하지 않는다. 매물 주소와 실제 이동 동선을 확인한 경우에만 선택한다.

| 지역 | 기본 문구 후보 | 선택 전 확인 사항 |
| --- | --- | --- |
| 북수리 | `삼성전자 온양캠퍼스 출퇴근 편리한 위치` | 해당 매물에서 캠퍼스까지의 실제 이동거리·교통수단 확인 |
| 공수리 | `삼성전자 온양캠퍼스 출퇴근 편리한 위치`<br>`도서관·수영장·체육관 이용 편리한 배방복합커뮤니티센터 생활권` | 캠퍼스·배방복합커뮤니티센터까지의 실제 이동거리·교통수단 확인 |
| 장재리 | `천안아산역과 배방 생활권 이용을 중요하게 보는 분께 추천드리는 위치입니다.` | 천안아산역·상업시설까지의 실제 이동거리와 교통수단 확인 |
| 월천지구 | `삼성전자 온양캠퍼스 출퇴근 편리한 위치` | 해당 매물에서 캠퍼스까지의 실제 이동거리·교통수단 확인 |

지역별 문구는 아래 후보 중 하나만 선택한다. 개별 매물의 실제 거리·교통수단을 확인한 뒤 선택한다.

```text
북수리: 삼성전자 온양캠퍼스 출퇴근 편리한 위치
북수리: 출퇴근과 일상생활의 균형을 갖춘 배방 생활권
북수리: 배방 생활권 중심에서 편하게 거주하기 좋은 위치
북수리: 생활 편의와 주거 환경을 함께 고려한 북수리 생활권
공수리: 삼성전자 온양캠퍼스 출퇴근 편리한 위치
공수리: 도서관·수영장·체육관 이용 편리한 배방복합커뮤니티센터 생활권
공수리: 교통과 생활 편의를 함께 누릴 수 있는 배방 생활권
공수리: 일상생활에 필요한 편의시설 이용이 좋은 공수리 생활권
공수리: 직장인과 실거주자 모두 고려하기 좋은 배방 생활권
장재리: 천안아산역과 배방 생활권 이용 편리한 위치
장재리: 광역 교통 이용을 중요하게 보는 분께 좋은 장재리 생활권
장재리: 천안아산역 중심 생활권을 누릴 수 있는 위치
장재리: 배방 생활권과 인근 업무지역 이동을 함께 고려한 위치
장재리: 교통 편의와 생활 인프라를 함께 갖춘 장재리 생활권
월천지구: 배방·탕정 생활권을 함께 누릴 수 있는 위치
월천지구: 삼성전자 온양캠퍼스 출퇴근 편리한 위치
월천지구: 배방 생활권에서 쾌적한 주거환경을 찾는 분께 좋은 위치
월천지구: 배방과 탕정 방향 생활권을 함께 고려한 월천지구
월천지구: 출퇴근과 생활 편의를 함께 챙길 수 있는 월천지구 생활권
```

`역세권`, `도보 n분`, `상권 바로 앞`, `출퇴근 최적`, `개발 확정·개통 예정`처럼 거리·완공·수요를 단정하는 표현은 주소별 확인값 없이 제공하지 않는다. 특히 월천지구~탕정지구 연결도로 및 월천지구~세교리 연결도로는 아산시 사업으로 추진 중이므로, 현재 광고의 즉시 이용 장점처럼 자동 표기하지 않는다.

# 7. 특징 문장 라이브러리

특징마다 미리 문장을 준비한다.

예:

## 붙박이장

```text
넉넉한 붙박이장이 있어 수납 활용도가 좋습니다.
```

## 베란다

```text
별도의 베란다 공간이 있어 생활공간 활용이 편리합니다.
```

## 양창

```text
창이 두 방향으로 있어 환기와 개방감이 좋은 구조입니다.
```

## 엘리베이터

```text
엘리베이터가 있어 층간 이동이 편리합니다.
```

## 주차

```text
건물 내 주차가 가능해 차량 이용도 편리합니다.
```

## 중문

```text
중문이 설치되어 있어 공간 분리와 냉난방 효율에 도움이 됩니다.
```

## 신축급

```text
전체적으로 깔끔하게 관리된 신축급 컨디션의 매물입니다.
```

## 풀옵션

```text
생활에 필요한 주요 가전이 갖춰져 있어 편하게 입주할 수 있습니다.
```

이 문장들은 코드 내 별도 dictionary 또는 설정파일 형태로 관리한다.

# 8. 광고 생성 구조

광고는 다음 구조로 생성한다.

## 광고 제목

```text
핵심 특징 + 구조 + 추가 장점
```

원룸·투룸은 각각 20개의 한 줄 제목 템플릿을 선택할 수 있게 한다. 선택한 템플릿 문구는 제목으로 그대로 사용하며, 직접 입력 제목 칸은 두지 않는다. `실매물`, `즉시 입주`, `채광`, `도보권`처럼 사실 확인이 필요한 제목은 확인된 매물에만 선택한다.

예:

```text
붙박이장 수납 좋은 투룸｜베란다·주차 가능
```

또는

```text
보증금 부담 낮은 투룸｜깔끔한 내부·주차 가능
```

---

## 광고 상세본문

기본 구조:

```text
[한 줄 핵심 소개]

📍 주소·건물명

✔ 핵심 포인트
✔ 구조·옵션·거래조건

🚉 교통 & 생활
[선택한 지역 문구와 직접 입력한 확인 내용]

💡 이런 분께 추천드려요
👉 템플릿별 추천 대상

📌 안내사항
```

# 15. 추가 강조내용

옵션 체크로 표현하기 어려운 특징을 위해 자유 입력란을 하나 제공한다.

예:


초기 버전에서는 이 내용을 AI로 해석하지 않는다.

사용자가 입력한 내용을 그대로 광고 중간에 추가하거나, 메모 형식으로 활용한다.

향후 필요하면 문장 자동 변환 기능을 추가할 수 있다.

# 16. 자동 템플릿 추천

초기 버전에서는 자동 추천을 구현하지 않는다.

사용자가 직접 템플릿을 선택한다.

향후 필요하면 다음 조건을 이용해 기본 템플릿을 자동 추천할 수 있다.

예:

```text
원룸 + 보증금 낮음
→ 원룸 저보증금형

원룸 + 옵션 많음
→ 원룸 신축·옵션형

투룸 + 붙박이장/베란다
→ 투룸 공간·수납형

투룸 + 엘리베이터 + 신축급
→ 투룸 신축·옵션형
```

단, 1차 구현에서는 불필요한 자동화를 넣지 않는다. DB 연동 기반 추천도 만들지 않는다.

# 17. 광고 글자수

당근부동산 광고를 기준으로 너무 긴 문구를 생성하지 않는다.

광고 상세문구는 기본적으로 **약 350~600자** 범위에서 생성하도록 한다.

최대 1,000자를 넘지 않는 것을 권장한다.

공통 안내사항도 글자수에 포함한다.

---

# 18. 공통 안내사항

모든 원룸·투룸 광고 하단에는 수정 가능한 기본 안내사항을 자동 추가한다. 다가구주택 전용면적 참고, 계약 가능 여부·옵션 변동, 상담·방문 예약 안내는 기본으로 넣는다. `본 매물은 실매물입니다`, `사진은 실제 호실 촬영본입니다`는 각각의 사실 확인 체크를 한 경우에만 자동 추가한다.

```text
📌 안내사항

✔ 계약 가능 여부 및 옵션은 실시간으로 변동될 수 있으므로 방문 전 문의 부탁드립니다.
✔ 자세한 상담 및 방문 예약은 언제든 편하게 연락 주세요.
```

향후 안내사항을 수정하기 쉽도록 별도 상수로 관리한다.

## 18-1. 지역 문구의 근거와 사용 기준

- 공수리의 배방복합커뮤니티센터는 아산시가 2024년 신축공사 완료를 안내했으며, 공공도서관·국민체육센터·다함께돌봄센터로 구성되어 있다. 다만 개별 매물에서의 접근성은 주소마다 다르므로 선택형 문구로만 쓴다.
- 삼성전자 온양캠퍼스는 아산시 자료상 배방읍 북수리 일원에 있으며 반도체 테스트·패키징 공정을 운영한다. 북수리·공수리·월천지구 매물에는 `삼성전자 온양캠퍼스 출퇴근 편리한 위치` 문구를 후보로 제공한다. 개별 매물의 실제 이동시간은 게시 전 확인한다.
- 장재리는 아산시 자료에서 KTX천안아산역 일원으로 확인되지만, 장재리 전체가 역 도보권이라는 뜻은 아니다. `천안아산역 이용` 문구는 실제 동선 확인 후에만 쓴다.
- 월천지구는 아산시 지구단위계획 대상이며, 탕정지구·세교리 연결도로 사업은 추진 단계다. 완료되지 않은 사업을 현재 생활 편의 또는 가치 상승처럼 광고에 쓰지 않는다.
- 북수리는 지역명만으로 특정 시설 접근성을 보장하지 않는다. 기본 문구는 배방·월천 생활권을 고려한다는 수준으로 제한한다.

문구의 사실 근거는 [아산시 삼성전자 온양캠퍼스 방문 안내](https://media.asan.go.kr/develop/m_keyword/?a_no=10&m_mode=news_list&search_day=20220918), [아산시 배방복합커뮤니티센터 신축공사 완료 안내](https://abn.asan.go.kr/develop/m_news/?PageNo=41&a_no=5&cate=news&m_mode=view&pds_no=2024022806270598506), [아산시 월천지구 지구단위계획](https://www.asan.go.kr/main/cms/?PageNo=9&category=&m_mode=view&no=59&pds_no=2022041520282905347&tb_nm=administrator_info), [아산시 월천지구~탕정지구 연결도로 사업 정보](https://www.asan.go.kr/sotong/develop/m_rds/?PageNo=1&m_mode=view&map_yn=Y&pds_no=2024032911111100140), [아산시 천안아산역·장재리 관련 계획 자료](https://www.asan.go.kr/main/files/plan_8th/2026%EB%85%84%EC%A4%91%EC%9E%A5%EA%B8%B0%EB%B0%9C%EC%A0%84%EA%B3%84%ED%9A%8D%EB%B3%B4%EA%B3%A0%EC%84%9C.pdf)를 기준으로 관리한다. 실제 광고 게시 전에는 현재 운영 여부와 매물별 위치를 다시 확인한다.

# 20. MVP 완료 기준

다음 기능이 정상 작동하면 1차 개발 완료로 판단한다.

1. 매물 등록·광고 현황 연결 없이 기본 조건을 직접 입력할 수 있다.
2. 초기 4개 광고 템플릿을 선택할 수 있다.
3. 강조할 특징을 선택할 수 있다.
4. 핵심 지역 4곳의 생활권 문구는 실제 위치 확인 후 1개를 선택해 넣을 수 있다.
5. 선택한 특징과 지역 문구에 따라 문장이 자동으로 추가된다.
6. 광고 제목이 자동 생성된다.
7. 광고 상세문구와 수정 가능한 공통 안내사항이 자동 생성된다.
8. 생성된 광고를 직접 수정할 수 있다.
9. 최종 광고문을 쉽게 복사할 수 있다.
10. 기존 매물·광고 현황·계약·상담 데이터에 영향을 주지 않는다.
11. 별도의 AI API 없이 동작한다.

# 22. Codex 검토 요청사항

기존 Streamlit 프로젝트를 확인한 뒤 다음 내용을 검토해 달라.

### 1.
현재 매물 DB와 연결하지 않고 최소 직접입력으로 광고 문구를 만들 수 있는가?

### 2.
이번 기능 구현을 위해 SQLite 테이블 변경이 필요한가?

DB 변경은 하지 않는다.

# 23. 최종 개발 방향

이번 기능은 새로운 시스템을 만드는 프로젝트가 아니다.

기존 매물관리 시스템에 아래 기능 하나를 추가하는 것이 목표다.

**최소 조건 직접입력과 옵션 체크를 활용하여 표준화된 광고문구를 빠르게 생성하고 복사하는 기능**

따라서 개발 과정에서도 확장성이나 복잡한 자동화보다 다음 기준을 우선한다.

**빠른 구현**
  
**간단한 유지관리**
  
**기존 시스템 영향 최소화**
  
**반복업무 감소**
  
**광고 품질 표준화**

최종 업무 흐름은 다음과 같다.

```text
기본 조건 직접 입력
↓
템플릿 선택
↓
강조 포인트 선택
↓
광고 생성
↓
필요 시 수정
↓
복사
↓
광고 플랫폼에 붙여넣기
```

이 흐름이 짧고 안정적으로 작동하면 이번 기능의 목적은 달성된 것으로 판단한다.
