> 표기 방법: **완료**는 코드와 기본 확인이 끝난 상태이며, **브라우저 확인 필요**는 실제 화면을 사람이 직접 눌러 보는 확인이 남았다는 뜻입니다.

## 현재 상태 요약

현재는 **7단계: 오늘의 매물 현황·검색·필터**까지 코드 구현을 마쳤습니다.

- 완료: 1~7단계의 코드 구현과 기본 자동 확인
- 남음: 각 단계의 실제 브라우저 화면 확인
- 다음 단계: 8단계 — 건물·호실 관리 화면

### 다음 단계에 반영된 사진 계획

- 사진 파일과 사진 보관 위치는 이 도구에서 관리하지 않는다.
- 7단계에서 매물별 `사진 보유 여부`를 `있음 / 없음 / 확인 필요`로 선택하고 필터할 수 있게 만든다.
- 사진 상태가 `촬영 필요`이거나 사진 보유 여부가 `없음`이면 `사진 촬영 필요` 업무로 표시한다.

### 추가 계획: 계약관리

- 계약관리는 별도 탭으로 만들되, 계약을 건물·호실에 직접 붙이지 않고 해당 매물 회차에 연결한다.
- 단기계약과 일반 계약의 시작일·종료일·기간·상태를 누적 관리한다.
- 계약자 개인정보, 계약금·잔금·결제, 계약서 파일은 관리하지 않는다.

### 추가 계획: 상담관리

- 상담관리는 계약관리와 분리한 가벼운 CRM 탭으로 만든다.
- 전화·문자·방문 등 상담 이력과 다음 연락일만 매물 회차에 연결해 누적한다.
- 고객 이름·연락처는 상담 상세에서만 관리하고, 자동 문자·방문 예약·민감 개인정보는 관리하지 않는다.

## 최근 완료: 7단계

### 구현된 내용

- 현재 매물 목록과 오늘 새 접수·퇴실 예정·재확인 필요·사진 촬영 필요·공실 요약을 표시함
- 건물명·지번·호수 검색과 접수일·상태·룸 형태·사진 상태·사진 보유 여부·확인 업무 필터를 제공함
- 여러 필터를 함께 적용하고 한 번에 초기화할 수 있음
- 사진 보유 여부를 `있음 / 없음 / 확인 필요`로 빠르게 수정할 수 있음
- 사진 상태가 촬영 필요이거나 사진 보유 여부가 없으면 사진 촬영 필요로 표시함
- 비밀번호와 내부 메모는 목록·빠른 수정에 표시하지 않음
- 상단 `새 매물 등록`을 누르면 이전 검색·선택·입력값을 모두 초기화함

| 기존 데이터 파일 확장 | 통과 | 기존 매물은 사진 보유 여부가 확인 필요로 시작 |
| 실제 브라우저 클릭 확인 | 미실시 | 다음 확인 때 진행 |
